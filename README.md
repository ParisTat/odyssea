# Odyssea

> 404: Home Not Found. Our shared trip planner.

Odyssea has a page for each trip: a day-by-day itinerary, a shared budget (totalled in EUR, with exchange rates stored per expense) and practical info.
The first trip is **Paris, 30 Dec 2026 – 4 Jan 2027**.

**Live:** https://paristat.github.io/odyssea/

## Quick start

```bash
npm ci
npm run dev
```

- **Where things stand:** [`HANDOFF.md`](HANDOFF.md)
- **What's planned:** [`docs/ROADMAP.md`](docs/ROADMAP.md)
- **How to contribute, add a trip, add an expense or add a language:** [`CONTRIBUTING.md`](CONTRIBUTING.md)

Stack: React 19, TypeScript, Vite, Tailwind CSS v4, React Router, i18next, zod, Vitest and Playwright. It is deployed to GitHub Pages.
