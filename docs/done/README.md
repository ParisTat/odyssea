# Done plans

This folder holds finished feature plans, moved here from `../plans/` when their PR merges.
Keep the file name (`NNN-name.md`). At the top, set **Status: Done** and add an **Outcome** note that covers:
- what shipped
- what changed compared with the plan
- any follow-ups (and add those to `../ROADMAP.md`)

That way anyone can see later why something was built the way it was.
